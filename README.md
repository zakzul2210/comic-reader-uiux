# Comic Reader Website

## About the Project
Comic Reader is a personal UI/UX design project inspired by online comic-reading platforms such as Shinigami. 

The project aims to create a simple, modern, and user-friendly website where users can seamlessly discover, search, and read their favorite comics.

## Project Goals
- Design an intuitive and visually appealing comic-reading interface.
- Enable users to discover and explore new comics effortlessly.
- Enhance the reading experience through a clean, distraction-free environment.
- Ensure a fully responsive layout tailored for both desktop and mobile users.

## Key Features
- **Comic Catalog:** Visual showcase with cover images, synopsis, and ratings.
- **Search & Filter:** Quick search with genre and status filtering options.
- **Comic Details Page:** Comprehensive view including chapter lists and release info.
- **Reader Interface:** Optimized reading mode with smooth chapter navigation.
- **Latest Updates:** Dedicated section for newly updated chapters.

## Design Process
1. **Empathize & Research:** Identify user needs, pain points, and preferences.
2. **Define:** Outline target audience and key user personas.
3. **Ideate & Structure:** Map out user flows and low-fidelity wireframes.
4. **UI Design:** Develop high-fidelity UI components and prototypes in Figma.
5. **Evaluate:** Gather feedback and iterate to refine the user experience.

## Tools Used
