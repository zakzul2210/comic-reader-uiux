# Comic Reader Website

## About the Project
Comic Reader is a personal UI/UX design project inspired by online comic reading platforms such as Shinigami.

The project aims to create a simple, modern, and user-friendly website where users can discover, search, and read their favorite comics.

## Project Goals
- Design an intuitive and visually appealing comic reading website.
- Make it easy for users to discover and explore comics.
- Improve the reading experience through a clean and comfortable interface.
- Create a responsive design for desktop and mobile users.

## Key Features
- Comic catalog with cover images and descriptions.
- Search and filter comics by genre.
- Comic details page with information and chapter lists.
- Reading interface with easy chapter navigation.
- Recently updated comics section.

## Design Process
1. Identify user needs and problems.
2. Define the target audience.
3. Create user flows and wireframes.
4. Develop the final UI design in Figma.
5. Evaluate and improve the user experience.
